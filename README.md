# casper01.github.io

My portfolio site: [casper01.github.io](https://casper01.github.io).

The page is generated by `build.py` from the metadata of my public GitHub repos (description,
website link, topics) plus a few overrides in `projects.toml`. A repo shows up when it has one of
the category topics (`ai`, `game`, `tool`, `university`, `puzzles`).

```bash
python build.py                  # build dist/ (Python 3.11+, standard library only)
python build.py --preview        # build every theme into dist/preview/<theme>/
```

GitHub Actions rebuilds and deploys the site on every push and once a day.
